1.1 Discrete-Time Representation of Sequences

A discrete-time signal is represented mathematically as a sequence of numbers $x[n]$ defined only for integer values of $n \in (-\infty, \infty)$. Unlike continuous-time functions $x_a(t)$, $x[n]$ is undefined between integer indices.

⚡ Fundamental Elementary Sequences
δ[n]
Unit Impulse (Kronecker Delta)
$$\delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \neq 0 \end{cases}$$ Any arbitrary sequence can be decomposed as a linear combination of weighted impulses: $x[n] = \sum_{k=-\infty}^{\infty} x[k] \delta[n-k]$.
u[n]
Unit Step Sequence
$$u[n] = \begin{cases} 1, & n \ge 0 \\ 0, & n < 0 \end{cases}, \quad u[n] = \sum_{k=-\infty}^n \delta[k] = \sum_{k=0}^\infty \delta[n-k]$$ Relationship: $\delta[n] = u[n] - u[n-1]$.
e^jωn
Complex Exponential Sequence
$$x[n] = A \alpha^n = |A| e^{j\phi} (|\alpha| e^{j\omega_0})^n = |A| |\alpha|^n e^{j(\omega_0 n + \phi)}$$ If $|\alpha| = 1$, $x[n] = e^{j\omega_0 n} = \cos(\omega_0 n) + j\sin(\omega_0 n)$.
📊 Architectural Flow: Discrete Frequency Spectrum & Oscillation Rates
Figure 1.1: Frequency range of discrete-time sinusoids. Unlike continuous time where frequency can grow to infinity, discrete frequency repeats every 2π and has maximum variation at ω = π.

1.2 Fundamental Differences Between Continuous and Discrete Sinusoids (MathWorks High-Yield)

Important
 1. Frequency Periodicity ($2\pi$):
$$e^{j(\omega_0 + 2\pi) n} = e^{j\omega_0 n} \cdot e^{j 2\pi n} = e^{j\omega_0 n} \cdot 1 = e^{j\omega_0 n}$$ All discrete frequencies $\omega$ separated by an integer multiple of $2\pi$ are physically indistinguishable. We only need to consider frequencies over an interval of length $2\pi$, typically $[-\pi, \pi]$ or $[0, 2\pi]$.

2. Highest Rate of Oscillation Occurs at $\omega = \pi$:
As $\omega_0$ increases from $0$ to $\pi$, the oscillation rate increases. At $\omega = \pi$, $x[n] = e^{j\pi n} = (-1)^n$, which alternates signs every single sample (highest rate of variation). As $\omega$ increases from $\pi$ to $2\pi$, the apparent rate of oscillation decreases until $\omega = 2\pi$ corresponds back to DC ($\omega = 0$).

3. Periodicity of the Sequence in Time:
A continuous sinusoid $\cos(\Omega_0 t)$ is always periodic in time for any $\Omega_0$. A discrete sinusoid $\cos(\omega_0 n)$ is periodic in time if and only if $\omega_0 / (2\pi)$ is a rational number: $$\frac{\omega_0}{2\pi} = \frac{k}{N} \implies N = \frac{2\pi k}{\omega_0} \in \mathbb{Z}^+$$

2.1 System Properties & Classification

Property Mathematical Condition LTI Impulse Response $h[n]$ Criterion
Linearity $\mathcal{T}\{a x_1[n] + b x_2[n]\} = a \mathcal{T}\{x_1[n]\} + b \mathcal{T}\{x_2[n]\}$ Satisfied if system consists only of additions, multiplications by constants, and delay elements.
Time-Invariance If $\mathcal{T}\{x[n]\} = y[n]$, then $\mathcal{T}\{x[n - n_0]\} = y[n - n_0]$ Impulse response $h[n]$ must not vary with the time of excitation: $\mathcal{T}\{\delta[n - k]\} = h[n - k]$.
Causality $y[n_0]$ depends only on $x[n]$ for $n \le n_0$. $h[n] = 0$ for all $n < 0$.
BIBO Stability If $|x[n]| \le B_x < \infty$, then $|y[n]| \le B_y < \infty$. $S = \sum_{n=-\infty}^{\infty} |h[n]| < \infty$ (Absolutely summable).

Figure 2.1: The 4 mathematical steps of convolution: Fold h[k] → Shift by n → Multiply point-by-point by x[k] → Sum over all k.

2.2 The Linear Convolution Sum

By linearity and time-invariance, the response of any LTI system to an arbitrary input $x[n] = \sum_{k=-\infty}^\infty x[k]\delta[n-k]$ is given by the convolution sum:

$$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] h[n - k] = \sum_{k=-\infty}^{\infty} h[k] x[n - k]$$
Tip
 Convolution Length Rule: If $x[n]$ has length $N_1$ ($n \in [0, N_1-1]$) and $h[n]$ has length $N_2$ ($n \in [0, N_2-1]$), the non-zero duration of $y[n]$ is: $$L_y = N_1 + N_2 - 1$$ Interviewers frequently ask this to verify memory preallocation in C or MATLAB!

2.3 Linear Constant-Coefficient Difference Equations (LCCDE)

An important class of discrete-time LTI systems is described by $N^{\text{th}}$-order difference equations:

$$\sum_{k=0}^N a_k y[n - k] = \sum_{m=0}^M b_m x[n - m], \quad a_0 \neq 0$$

For the system to be linear, time-invariant, and causal, it must satisfy the condition of initial rest: if $x[n] = 0$ for $n < n_0$, then $y[n] = 0$ for $n < n_0$.

3.1 Eigenfunctions of LTI Systems

When an LTI system with impulse response $h[n]$ is excited by a complex exponential $x[n] = e^{j\omega n}$:

$$y[n] = \sum_{k=-\infty}^\infty h[k] e^{j\omega (n - k)} = \left( \sum_{k=-\infty}^\infty h[k] e^{-j\omega k} \right) e^{j\omega n} = H(e^{j\omega}) e^{j\omega n}$$

Hence, complex exponentials are eigenfunctions of LTI systems, and the eigenvalue $H(e^{j\omega})$ is the Frequency Response of the system.

⚡ Dual Domain Duality: Convolution vs. Modulation
Figure 3.1: Fundamental duality theorems of the DTFT. Operations in time map to their duals in frequency.

3.2 The Discrete-Time Fourier Transform (DTFT)

Analysis Equation (Forward DTFT) Synthesis Equation (Inverse DTFT)
$$X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x[n] e^{-j\omega n}$$ $$x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega$$

3.3 Symmetry Properties for Real Sequences

If $x[n]$ is real-valued, $X(e^{-j\omega}) = X^*(e^{j\omega})$ (Conjugate Symmetry):

  • Real Part $\operatorname{Re}\{X(e^{j\omega})\}$: Even function of $\omega$ ($\operatorname{Re}\{X(e^{j\omega})\} = \operatorname{Re}\{X(e^{-j\omega})\}$).
  • Imaginary Part $\operatorname{Im}\{X(e^{j\omega})\}$: Odd function of $\omega$ ($\operatorname{Im}\{X(e^{j\omega})\} = -\operatorname{Im}\{X(e^{-j\omega})\}$).
  • Magnitude Spectrum $|X(e^{j\omega})|$: Even function of $\omega$.
  • Phase Spectrum $\arg X(e^{j\omega})$: Odd function of $\omega$.

3.4 Essential DTFT Theorems (Oppenheim Table 2.2)

T1
Time Shifting & Frequency Shifting
$$x[n - n_0] \stackrel{\mathcal{F}}{\longleftrightarrow} e^{-j\omega n_0} X(e^{j\omega}), \quad e^{j\omega_0 n} x[n] \stackrel{\mathcal{F}}{\longleftrightarrow} X(e^{j(\omega - \omega_0)})$$
T2
Convolution Theorem
$$x[n] * h[n] \stackrel{\mathcal{F}}{\longleftrightarrow} X(e^{j\omega}) \cdot H(e^{j\omega})$$ Convolution in the time domain is equivalent to point-by-point multiplication in the frequency domain.
T3
Modulation / Windowing Theorem
$$x[n] \cdot w[n] \stackrel{\mathcal{F}}{\longleftrightarrow} \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\theta}) W(e^{j(\omega - \theta)}) d\theta = \frac{1}{2\pi} X(e^{j\omega}) \circledast W(e^{j\omega})$$ Multiplication in time results in periodic circular convolution in frequency (the mathematical source of spectral leakage).
T4
Parseval’s Energy Theorem
$$E = \sum_{n=-\infty}^\infty |x[n]|^2 = \frac{1}{2\pi} \int_{-\pi}^{\pi} |X(e^{j\omega})|^2 d\omega$$ Total energy in time domain equals total energy in frequency domain.

4.1 Definition & Relation to DTFT

The bilateral $z$-transform generalizes the Fourier transform to complex frequencies $z = r e^{j\omega}$:

$$X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n}$$

When evaluated on the unit circle ($|z| = r = 1$), the $z$-transform reduces identically to the DTFT: $X(e^{j\omega}) = X(z)\big|_{z = e^{j\omega}}$. For the DTFT to exist, the unit circle must lie within the Region of Convergence (ROC).

⭕ The Complex z-Plane: Unit Circle & ROC Boundaries
Figure 4.1: The z-plane geometry. For causal systems, ROC is exterior to outermost pole. Stability requires the unit circle |z|=1 to lie inside the ROC.

4.2 All Properties of the Region of Convergence (ROC)

Note
  1. The ROC is a ring or disk in the $z$-plane centered at the origin: $r_R < |z| < r_L$.
  2. The Fourier transform of $x[n]$ converges absolutely $\iff$ the ROC includes the unit circle $|z| = 1$.
  3. The ROC cannot contain any poles.
  4. If $x[n]$ is a finite-duration sequence, the ROC is the entire $z$-plane, except possibly $z = 0$ (if $x[n]$ has non-zero values for $n > 0$) and/or $z = \infty$ (if $x[n]$ has non-zero values for $n < 0$).
  5. If $x[n]$ is a right-sided sequence (causal-type), the ROC extends outward from the outermost finite pole to infinity: $|z| > r_{\max}$.
  6. If $x[n]$ is a left-sided sequence (anti-causal), the ROC extends inward from the innermost non-zero pole to zero: $|z| < r_{\min}$.
  7. If $x[n]$ is a two-sided sequence, the ROC is an open ring between two concentric circles containing no poles: $r_1 < |z| < r_2$.

4.3 Inverse z-Transform by Partial Fraction Expansion

For rational system functions $X(z) = \frac{P(z)}{Q(z)}$, expand $X(z)$ in partial fractions of $z^{-1}$:

$$X(z) = \sum_{k=1}^N \frac{A_k}{1 - d_k z^{-1}}$$

Each individual term maps according to the specified ROC:

  • If ROC is $|z| > |d_k|$ (Right-sided): $\frac{1}{1 - d_k z^{-1}} \longleftrightarrow d_k^n u[n]$
  • If ROC is $|z| < |d_k|$ (Left-sided): $\frac{1}{1 - d_k z^{-1}} \longleftrightarrow -d_k^n u[-n - 1]$

5.1 The System Function (Transfer Function)

Applying the convolution property $\mathcal{Z}\{x[n] * h[n]\} = X(z) H(z)$, the system transfer function is:

$$H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{m=0}^M b_m z^{-m}}{1 + \sum_{k=1}^N a_k z^{-k}} = b_0 \frac{\prod_{m=1}^M (1 - c_m z^{-1})}{\prod_{k=1}^N (1 - d_k z^{-1})}$$

where $c_m$ are system zeros, and $d_k$ are system poles.

⚖️ Decision Flow: Causality and BIBO Stability Verification
Step 1
Compute Poles of System Function H(z)
Solve denominator polynomial roots: $1 + \sum_{k=1}^N a_k z^{-k} = 0 \implies d_1, d_2, \dots, d_N$.
Step 2
Check Pole Magnitudes for Causal System
For causality, ROC is $|z| > \max_k |d_k|$. For BIBO stability, unit circle $|z|=1$ must lie inside ROC.
Result
Stability Condition
A causal LTI system is BIBO stable if and only if all poles satisfy $|d_k| < 1$ (strictly inside the unit circle).

6.1 Periodic Sampling & Spectral Replication

Sampling a continuous signal $x_a(t)$ with interval $T$ creates discrete sequence $x[n] = x_a(n T)$. In the frequency domain, the spectrum of the sampled sequence $X(e^{j\omega})$ is an infinite periodic sum of shifted replicas of $X_a(j\Omega)$:

$$X(e^{j\omega}) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X_a\left( j\left(\frac{\omega - 2\pi k}{T}\right) \right)$$

where continuous frequency $\Omega$ and discrete frequency $\omega$ are linked by: $\omega = \Omega T$.

🔄 End-to-End Discrete-Time Processing of Continuous Signals
Figure 6.1: Complete DSP signal chain. Continuous signal is prefiltered, sampled, digitally processed, and reconstructed via D/C sinc interpolation.

6.2 The Nyquist-Shannon Sampling Theorem

Important
 Let $x_a(t)$ be a bandlimited continuous signal with $X_a(j\Omega) = 0$ for $|\Omega| > \Omega_N$. Then $x_a(t)$ is uniquely determined by its samples $x[n] = x_a(nT)$ if and only if: $$\Omega_s = \frac{2\pi}{T} \ge 2 \Omega_N \iff f_s \ge 2 f_N$$ If $f_s < 2 f_N$, spectral copies overlap, corrupting the signal by aliasing. Frequencies fold back according to: $$f_{\text{alias}} = |f_0 - k f_s| \le \frac{f_s}{2}$$

6.3 Ideal Reconstruction (Whittaker-Shannon Sinc Interpolation)

Passing the impulse-modulated sampled signal through an ideal analog lowpass reconstruction filter with gain $T$ and cutoff $\Omega_c = \pi / T$ recovers the continuous signal exactly:

$$x_a(t) = \sum_{n=-\infty}^{\infty} x[n] \cdot \operatorname{sinc}\left( \frac{t - n T}{T} \right), \quad \text{where } \operatorname{sinc}(u) = \frac{\sin(\pi u)}{\pi u}$$

7.1 Decimation by Integer Factor $M$ (Downsampling)

Decimation reduces the sampling rate by factor $M$. To prevent aliasing at the lower rate, the signal must first pass through a digital anti-aliasing lowpass filter with cutoff $\omega_c = \pi / M$, followed by a compressor that retains every $M^{\text{th}}$ sample:

$$y[m] = x[m M], \quad Y(e^{j\omega}) = \frac{1}{M} \sum_{k=0}^{M-1} X\left(e^{j\frac{\omega - 2\pi k}{M}}\right)$$
📉 Multirate Building Blocks: Decimation vs. Interpolation
Figure 7.1: Fundamental multirate operations. Downsampling requires an anti-aliasing filter before compression; upsampling requires an anti-imaging filter after expansion.

7.2 Polyphase Decomposition & Computational Savings

A transfer function $H(z)$ can be decomposed into $M$ polyphase components:

$$H(z) = \sum_{k=0}^{M-1} z^{-k} E_k(z^M)$$
Tip
 The Noble Identity: Filtering by $E_k(z^M)$ followed by downsampling by $M$ is mathematically identical to downsampling by $M$ first, then filtering by $E_k(z)$.
Computational Benefit: Filtering occurs at the low decimated sampling rate $f_s/M$ rather than the high rate $f_s$, reducing arithmetic operations by a factor of $M$!
Oppenheim 4.8 - 4.9 Module 8: A/D Conversion, Quantization Noise & Noise Shaping
▼

8.1 Statistical Model of Quantization Errors

When an analog voltage is quantized by a $(B+1)$-bit uniform analog-to-digital converter with full-scale range $[-X_m, X_m]$, the quantization step size is:

$$\Delta = \frac{2 X_m}{2^{B+1}} = \frac{X_m}{2^B}$$

Assuming the quantization error $e[n]$ is uniformly distributed between $[-\Delta/2, \Delta/2]$ and uncorrelated with the input signal, the quantization noise variance is:

$$\sigma_e^2 = \frac{\Delta^2}{12} = \frac{X_m^2 2^{-2B}}{12}$$
📡 Noise Shaping Architecture: First-Order Sigma-Delta (ΣΔ) Converter
Figure 8.1: First-order sigma-delta noise shaping loop. Feedback integrator shapes quantization noise by Hn(z) = 1 - z^-1, pushing noise outside the baseband.

8.2 The 6 dB Per Bit Rule (SQNR)

For a full-scale sinusoidal input of amplitude $X_m$, the signal power is $\sigma_x^2 = X_m^2 / 2$. The Signal-to-Quantization-Noise Ratio is:

$$\text{SQNR} = 10 \log_{10}\left( \frac{\sigma_x^2}{\sigma_e^2} \right) = 10 \log_{10}\left( \frac{X_m^2 / 2}{X_m^2 2^{-2B} / 12} \right) = 10 \log_{10}(1.5 \cdot 2^{2B}) \approx 6.02 B + 1.76 \text{ dB}$$

Every additional bit of ADC wordlength improves dynamic range by approximately $6\text{ dB}$.

9.1 Phase and Group Delay

The frequency response of an LTI system is a complex function of frequency: $H(e^{j\omega}) = |H(e^{j\omega})| e^{j\theta(\omega)}$.

  • Phase Response: $\theta(\omega) = \arg H(e^{j\omega})$
  • Phase Delay: $\tau_p(\omega) = -\frac{\theta(\omega)}{\omega}$
  • Group Delay: $\tau_g(\omega) = -\frac{d}{d\omega} \left[ \theta(\omega) \right]$
🔍 Geometric Pole-Zero Vector Evaluation in the Complex Plane
Figure 9.1: Geometric magnitude and phase evaluation. |H(e^jω)| equals product of vector lengths from zeros divided by product of vector lengths from poles. Proximity to a pole creates a resonance peak.

9.2 Physical Meaning of Group Delay Distortion

Warning
 Group delay represents the effective time delay experienced by a narrow-band wave packet centered at frequency $\omega$. If $\tau_g(\omega)$ is constant for all $\omega$, all frequency components travel through the system with identical delay, preserving waveform fidelity.

If $\tau_g(\omega)$ varies with frequency (as in all non-linear phase IIR filters), different frequency components arrive at different times. This causes dispersion, severely distorting ECG pulses in biomedical instruments and causing Inter-Symbol Interference (ISI) in high-speed digital communications!

A stable, causal LTI system is minimum-phase if and only if all of its poles AND all of its zeros lie strictly inside the unit circle.

12.1 Sources of Finite-Wordlength Errors

E1
A/D Input Quantization
Quantizing continuous sensor samples to $B+1$ bits introduces white additive noise of variance $\sigma_e^2 = \Delta^2 / 12$.
E2
Coefficient Quantization
Truncating filter coefficients $b_k, a_k$ shifts pole and zero locations in the $z$-plane, distorting cutoff frequency and risking instability.
E3
Arithmetic Round-Off & Accumulation Noise
Multiplying two $(B+1)$-bit numbers yields a $2B$-bit product. Quantizing back to $(B+1)$ bits injects round-off noise into the feedback loop.
E4
Dynamic Range Overflow & Limit Cycles
In Two's complement arithmetic, positive overflow wraps around to large negative numbers, exciting sustained non-linear periodic oscillations (limit cycles).

13.1 Filter Design Specifications

Filter requirements are defined in four parameters:

  • Passband cutoff: $\omega_p$, Passband ripple: $\delta_1$ (or $R_p = -20\log_{10}(1 - \delta_1)\text{ dB}$)
  • Stopband cutoff: $\omega_s$, Stopband attenuation: $\delta_2$ (or $A_s = -20\log_{10}(\delta_2)\text{ dB}$)
  • Transition band: $\Delta\omega = \omega_s - \omega_p$
🔄 The 4-Step Bilinear Transformation Design Pipeline
Step 1
Specify Digital Filter Cutoffs
Target discrete frequencies $\omega_p, \omega_s$ and ripple bounds $R_p, A_s$.
Step 2
Pre-Warp Analog Prototype Frequencies
$$\Omega_p = \frac{2}{T_s} \tan\left(\frac{\omega_p}{2}\right), \quad \Omega_s = \frac{2}{T_s} \tan\left(\frac{\omega_s}{2}\right)$$
Step 3
Synthesize Analog Prototype Transfer Function Ha(s)
Compute poles and zeros for analog Butterworth, Chebyshev, or Elliptic filter.
Step 4
Apply Bilinear Transformation (BLT)
Substitute $s = \frac{2}{T_s} \frac{1 - z^{-1}}{1 + z^{-1}}$ into $H_a(s)$ to obtain final discrete filter $H(z)$.

16.1 O(1) Circular Buffer for Streaming DSP in C

#include <stdlib.h>
#include <stdbool.h>

typedef struct {
    float *buffer;
    size_t capacity;
    size_t head;
    size_t count;
    double running_sum;
} RingBufferFilter;

RingBufferFilter* ring_init(size_t window_size) {
    RingBufferFilter *f = (RingBufferFilter *)malloc(sizeof(RingBufferFilter));
    if (!f) return NULL;
    f->buffer = (float *)calloc(window_size, sizeof(float));
    if (!f->buffer) { free(f); return NULL; }
    f->capacity = window_size;
    f->head = 0;
    f->count = 0;
    f->running_sum = 0.0;
    return f;
}

float ring_process(RingBufferFilter *f, float sample) {
    f->running_sum -= f->buffer[f->head];      // Subtract oldest sample
    f->buffer[f->head] = sample;               // Insert new sample
    f->running_sum += sample;
    
    // Power of 2 bitwise modulo optimization:
    f->head = (f->head + 1) % f->capacity;
    if (f->count < f->capacity) f->count++;
    return (float)(f->running_sum / f->count);
}

Q1: Multi-Tone Sampling & Aliasing

Given $x(t) = 3\cos(600\pi t) + 2\cos(1800\pi t) + \sin(3000\pi t)$ sampled at $f_s = 1200\text{ Hz}$: What is the Nyquist rate, and what discrete frequencies appear in the sampled signal?

Model Answer: Frequencies are $300\text{ Hz}$, $900\text{ Hz}$, and $1500\text{ Hz}$. Nyquist rate $2 f_{\max} = 3000\text{ Hz}$. Folding limit is $f_s/2 = 600\text{ Hz}$. $300\text{ Hz}$ remains at $300\text{ Hz}$; $900\text{ Hz}$ aliases to $|900 - 1200| = 300\text{ Hz}$; $1500\text{ Hz}$ aliases to $|1500 - 1200| = 300\text{ Hz}$. All three tones collapse into the single alias frequency of $300\text{ Hz}$!

Q2: Why does MATLAB filter implement Direct Form II Transposed?

Model Answer: It uses canonical $\max(M, N)$ delay elements, sums multiplications directly into delay registers (optimal for hardware FMA instructions), eliminates internal summing node overflow inherent to standard Direct Form II, and achieves superior fixed-point round-off noise performance.
