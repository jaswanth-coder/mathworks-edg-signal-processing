1. Digital Signal Processing (DSP) Core Theory

Rigorous breakdown of LTI systems, Sampling, Aliasing, Transforms (DTFT, Z, DFT, FFT), FIR/IIR Filter Design, Multirate Processing, and Spectral Estimation tailored for the MathWorks EDG interview.

🔍 Nyquist & Aliasing

Sampling at $f_s \ge 2 f_{\max}$ prevents spectral overlap. Apparent folding frequency: $f_{\text{alias}} = |f_0 - k f_s| \le f_s/2$.

⚡ FFT Speedup

Direct DFT requires $O(N^2)$ complex operations. Radix-2 Cooley-Tukey DIT butterfly reduces this to $O(N \log_2 N)$.

🎛️ Filter Trade-off

FIR guarantees exact linear phase ($\tau_g = M/2$) & stability; IIR achieves steep roll-off at $5\times$ to $10\times$ lower order.

Figure 1.1: Frequency domain periodic replication upon sampling. If $f_s < 2 f_{\max}$, neighboring replicas overlap, resulting in irreversible aliasing.

1.1 Discrete-Time Fourier Transform (DTFT) & Z-Transform

The DTFT of a sequence $x[n]$ is defined as:

$$X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x[n] e^{-j\omega n}$$

💡 Critical Interview Trap: DTFT vs DFT vs Continuous-Time
  • DTFT is continuous and periodic with $2\pi$. The highest physical frequency in discrete time is always at $\omega = \pi$ (which corresponds to $f_s/2$).
  • DFT is discrete and finite-length ($N$): it samples the DTFT at $N$ discrete frequency bins $\omega_k = \frac{2\pi k}{N}$.
  • Z-Transform evaluates to DTFT when evaluated on the unit circle ($z = e^{j\omega}$), which requires the unit circle $|z|=1$ to be inside the Region of Convergence (ROC).

1.2 Radix-2 Cooley-Tukey FFT & The Butterfly Operation

An $N$-point DFT ($N = 2^M$) is decimated into even and odd index sequences:

$$X[k] = E[k] + W_N^k O[k], \quad X[k + N/2] = E[k] - W_N^k O[k]$$

Figure 1.2: Radix-2 DIT Butterfly computation unit. Reusing the product $W_N^k O[k]$ is the cornerstone of FFT speedup.

1.3 Filter Realization: Direct Form II Transposed

Why does MathWorks standardize on Direct Form II Transposed for filter.m?

Architecture Delay Elements (Registers) Internal Overflow Risk Accumulator Friendly

2.1 Vectorization vs. Slow MATLAB Loops

⚠️ MathWorks Coding Benchmark
MathWorks code reviews strictly penalize: (1) Growing arrays dynamically inside loops without preallocation, (2) Using nested loops for element-wise or sliding window operations when vectorized primitives (`cumsum`, `conv`, `filter`) exist. 
% BAD: Dynamic array growth in loop -> O(N^2) memory reallocations!
y = [];
for i = 1:100000
    y(i) = sin(2*pi*50*i/1000);
end

% GOOD: Contiguous preallocation -> O(N)
y = zeros(1, 100000);
for i = 1:100000
    y(i) = sin(2*pi*50*i/1000);
end

% BEST: Vectorized SIMD execution -> 100x Faster
n = 1:100000;
y = sin(2*pi*50*n/1000);

2.2 In-Place Peak Detection (`findpeaks` Under the Hood)

function [pks, locs] = custom_peak_detect(x, min_height, min_dist)
    x = x(:).';
    N = length(x);
    if N < 3, pks = []; locs = []; return; end
    
    % Vectorized interior local maxima mask
    is_peak = (x(2:N-1) > x(1:N-2)) & (x(2:N-1) > x(3:N)) & (x(2:N-1) >= min_height);
    candidate_locs = find(is_peak) + 1;
    
    % Enforce minimum distance between adjacent peaks
    if isempty(candidate_locs) || min_dist <= 1
        locs = candidate_locs;
        pks = x(locs);
        return;
    end
    
    % Sort candidates by amplitude descending to retain strongest peaks
    [~, sort_idx] = sort(x(candidate_locs), 'descend');
    sorted_locs = candidate_locs(sort_idx);
    keep = true(size(sorted_locs));
    
    for i = 1:length(sorted_locs)
        if keep(i)
            % Suppress neighbors within min_dist
            suppress = abs(sorted_locs - sorted_locs(i)) < min_dist;
            suppress(i) = false; % Keep current peak
            keep(suppress) = false;
        end
    end
    
    locs = sort(sorted_locs(keep));
    pks = x(locs);
end

3.1 Circular Buffer (Ring Buffer) for Real-Time DSP

Audio and sensor processing pipelines cannot afford $O(N)$ data shifting when a new sample arrives. A circular buffer achieves $O(1)$ push and access:

Figure 3.1: Circular buffer memory indexing. Zero-copy streaming input buffer.
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct {
    float *buffer;
    size_t capacity;
    size_t head;
    size_t count;
    double running_sum;
} StreamMovAvg;

StreamMovAvg* movavg_init(size_t window_size) {
    if (window_size == 0) return NULL;
    StreamMovAvg *f = (StreamMovAvg *)malloc(sizeof(StreamMovAvg));
    if (!f) return NULL;
    f->buffer = (float *)calloc(window_size, sizeof(float));
    if (!f->buffer) { free(f); return NULL; }
    f->capacity = window_size;
    f->head = 0;
    f->count = 0;
    f->running_sum = 0.0;
    return f;
}

// O(1) Moving Average update per incoming sample
float movavg_process(StreamMovAvg *f, float new_sample) {
    f->running_sum -= f->buffer[f->head];      // Subtract oldest sample
    f->buffer[f->head] = new_sample;           // Store new sample
    f->running_sum += new_sample;              // Add new sample
    
    f->head = (f->head + 1) % f->capacity;     // Advance pointer
    if (f->count < f->capacity) f->count++;
    
    return (float)(f->running_sum / f->count);
}

3.2 C 1D Linear Convolution with Boundary Safety

/**
 * Computes linear convolution y = x * h
 * Output length len_y = len_x + len_h - 1
 */
float* convolve_1d(const float *x, size_t len_x, const float *h, size_t len_h, size_t *len_y) {
    if (!x || !h || len_x == 0 || len_h == 0) return NULL;
    
    *len_y = len_x + len_h - 1;
    float *y = (float *)calloc(*len_y, sizeof(float));
    if (!y) return NULL;

    for (size_t n = 0; n < *len_y; ++n) {
        float sum = 0.0f;
        size_t k_min = (n >= len_h - 1) ? n - (len_h - 1) : 0;
        size_t k_max = (n < len_x - 1) ? n : len_x - 1;

        for (size_t k = k_min; k <= k_max; ++k) {
            sum += x[k] * h[n - k];
        }
        y[n] = sum;
    }
    return y;
}

3.3 Fixed-Point Saturation Arithmetic (Q15 Format)

#include <stdint.h>

typedef int16_t q15_t;

// Saturating addition: prevents wrap-around distortion in audio DSP
q15_t q15_add_sat(q15_t a, q15_t b) {
    int32_t sum = (int32_t)a + (int32_t)b;
    if (sum > 32767) return 32767;
    if (sum < -32768) return -32768;
    return (q15_t)sum;
}

// Q15 fixed-point multiplication
q15_t q15_mul(q15_t a, q15_t b) {
    int32_t prod = ((int32_t)a * (int32_t)b) >> 15;
    if (prod > 32767) return 32767;
    if (prod < -32768) return -32768;
    return (q15_t)prod;
}

🎯 Common Interview Gotchas & Traps

1. "Does zero-padding increase frequency resolution?"
NO. Zero-padding merely interpolates the DTFT (spectral density). True resolution requires increasing physical observation time $T_{\text{record}}$.

2. "Can a causal and stable IIR filter have exact linear phase?"
NO. Linear phase requires pole symmetry ($p$ and $1/p^*$). If poles are inside the unit circle for stability, reciprocal poles must lie outside, violating causality.

3. "Why does Type II FIR fail for Highpass filters?"
Type II FIR (symmetric, even length $N$) has a mandatory zero at $\omega = \pi$. Hence, it cannot pass high frequencies.

DSP Q1: Sampling & Aliasing with Multi-Tone Sinusoids
▾ Expand

Interviewer Prompt:
"Consider the continuous-time signal $x_a(t) = 3\cos(600\pi t) + 2\cos(1800\pi t) + \sin(3000\pi t)$.
1. What is the minimum Nyquist rate $f_s$?
2. If sampled at $f_s = 1200\text{ Hz}$, what discrete frequencies appear in $[0, f_s/2]$?"

Model Answer & Derivation

Part 1: Frequencies are $f_1 = 300\text{ Hz}$, $f_2 = 900\text{ Hz}$, $f_3 = 1500\text{ Hz}$. Maximum frequency $f_{\max} = 1500\text{ Hz}$.
Nyquist rate $f_{\text{Nyquist}} = 2 f_{\max} = \mathbf{3000\text{ Hz}}$.

Part 2: When sampled at $f_s = 1200\text{ Hz}$, folding limit is $f_s/2 = 600\text{ Hz}$:
- $300\text{ Hz}$ remains $\mathbf{300\text{ Hz}}$ (no aliasing).
- $900\text{ Hz}$ aliases: $|900 - 1200| = \mathbf{300\text{ Hz}}$.
- $1500\text{ Hz}$ aliases: $|1500 - 1200| = \mathbf{300\text{ Hz}}$.
All 3 tones collapse onto the single frequency of 300 Hz!

Time Complexity: $O(N^2)$, Auxiliary Space: $O(1)$.

DSP Q5: Bilinear Transformation & Frequency Warping
▾ Expand

Interviewer Prompt:
"Why does the Bilinear Transformation avoid aliasing where the Impulse Invariance method fails? Why is frequency pre-warping necessary?"

Theoretical Proof

Bilinear transform maps the continuous frequency axis $\Omega \in (-\infty, \infty)$ non-linearly to the unit circle $\omega \in (-\pi, \pi)$ via $\omega = 2\arctan(\frac{\Omega T_s}{2})$. Because the entire infinite axis is compressed onto one revolution of the unit circle, no aliasing occurs. Pre-warping $\Omega_c = \frac{2}{T_s}\tan(\frac{\omega_c}{2})$ ensures the desired cutoff frequency lands on the exact target bin.
