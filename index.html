1.1 Discrete-Time Representation of Sequences

A discrete-time signal is represented mathematically as a sequence of numbers $x[n]$ defined only for integer values of $n \in (-\infty, \infty)$. Unlike continuous-time functions $x_a(t)$, $x[n]$ is undefined between integer indices.

⚡ Fundamental Elementary Sequences
δ[n]
Unit Impulse (Kronecker Delta)
$$\delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \neq 0 \end{cases}$$ Any arbitrary sequence can be decomposed as a linear combination of weighted impulses: $x[n] = \sum_{k=-\infty}^{\infty} x[k] \delta[n-k]$.
u[n]
Unit Step Sequence
$$u[n] = \begin{cases} 1, & n \ge 0 \\ 0, & n < 0 \end{cases}, \quad u[n] = \sum_{k=-\infty}^n \delta[k] = \sum_{k=0}^\infty \delta[n-k]$$ Relationship: $\delta[n] = u[n] - u[n-1]$.
e^jωn
Complex Exponential Sequence
$$x[n] = A \alpha^n = |A| e^{j\phi} (|\alpha| e^{j\omega_0})^n = |A| |\alpha|^n e^{j(\omega_0 n + \phi)}$$ If $|\alpha| = 1$, $x[n] = e^{j\omega_0 n} = \cos(\omega_0 n) + j\sin(\omega_0 n)$.

📖 Oppenheim Worked Example 2.1: Determining the Periodicity of Discrete Sinusoids

Problem Statement: Consider the discrete sinusoidal sequence $x_1[n] = \cos\left(\frac{3\pi}{8} n\right)$ and $x_2[n] = \cos\left(\frac{3}{8} n\right)$. Determine whether each sequence is periodic in time. If periodic, compute its fundamental period $N$.

Solution:
A discrete sequence $\cos(\omega_0 n)$ is periodic if and only if $\frac{\omega_0}{2\pi}$ is a rational number $\frac{k}{N}$ where $k, N \in \mathbb{Z}^+$ are co-prime.
1. For $x_1[n]$: $\omega_0 = \frac{3\pi}{8}$. The ratio is: $$\frac{\omega_0}{2\pi} = \frac{3\pi / 8}{2\pi} = \frac{3}{16}$$ Since $3/16$ is a ratio of integers with $\gcd(3, 16) = 1$, $x_1[n]$ is strictly periodic with fundamental period $N = 16$ samples.
2. For $x_2[n]$: $\omega_0 = \frac{3}{8}$. The ratio is: $$\frac{\omega_0}{2\pi} = \frac{3/8}{2\pi} = \frac{3}{16\pi}$$ Because $\pi$ is transcendental, $\frac{3}{16\pi}$ is irrational. There exists no integer $N$ such that $x_2[n+N] = x_2[n]$ for all $n$. Thus, $x_2[n]$ is aperiodic despite looking like a sinusoid!

Key Takeaway for MathWorks Interview: Never assume a sampled continuous sinusoid is automatically periodic in discrete time without checking if $\omega_0 / (2\pi) \in \mathbb{Q}$.

Question: Find the fundamental period $N$ for each of the following periodic sequences:

  1. $x_a[n] = e^{j(2\pi/3)n} + e^{j(3\pi/4)n}$
  2. $x_b[n] = \sin\left(\frac{7\pi}{12} n\right) \cos\left(\frac{\pi}{4} n\right)$
Click to Reveal Step-by-Step Solution

Solution to 1:
For $e^{j(2\pi/3)n}$, $f_1 = \frac{2\pi/3}{2\pi} = \frac{1}{3} \implies N_1 = 3$.
For $e^{j(3\pi/4)n}$, $f_2 = \frac{3\pi/4}{2\pi} = \frac{3}{8} \implies N_2 = 8$.
The composite period $N = \operatorname{lcm}(N_1, N_2) = \operatorname{lcm}(3, 8) = \mathbf{24}$.

Solution to 2:
Use product-to-sum identity: $\sin(A)\cos(B) = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$.
$A+B = \frac{7\pi}{12} + \frac{3\pi}{12} = \frac{10\pi}{12} = \frac{5\pi}{6} \implies f_1 = \frac{5\pi/6}{2\pi} = \frac{5}{12} \implies N_1 = 12$.
$A-B = \frac{7\pi}{12} - \frac{3\pi}{12} = \frac{4\pi}{12} = \frac{\pi}{3} \implies f_2 = \frac{\pi/3}{2\pi} = \frac{1}{6} \implies N_2 = 6$.
Fundamental period $N = \operatorname{lcm}(12, 6) = \mathbf{12}$.

📖 Oppenheim Worked Example 2.14: Analytical Convolution of Real Exponential Sequences

Problem Statement: An LTI system has impulse response $h[n] = a^n u[n]$ with $|a| < 1$. The input is a unit step sequence $x[n] = u[n]$. Compute the analytical expression for output $y[n] = x[n] * h[n]$.

Step-by-step Derivation:
By definition of convolution: $$y[n] = \sum_{k=-\infty}^{\infty} x[k] h[n - k] = \sum_{k=-\infty}^{\infty} u[k] a^{n-k} u[n - k]$$ 1. Notice $u[k] = 0$ for $k < 0$, which sets the lower summation limit to $k = 0$.
2. Notice $u[n - k] = 0$ for $k > n$, which sets the upper summation limit to $k = n$.
3. For $n < 0$, the limits overlap vacuously, so $y[n] = 0$ for $n < 0$.
4. For $n \ge 0$: $$y[n] = \sum_{k=0}^n a^{n-k} = a^n \sum_{k=0}^n a^{-k} = a^n \sum_{k=0}^n (a^{-1})^k = a^n \left( \frac{1 - a^{-(n+1)}}{1 - a^{-1}} \right) = \frac{1 - a^{n+1}}{1 - a}$$ Combining results with the unit step: $$y[n] = \left( \frac{1 - a^{n+1}}{1 - a} \right) u[n]$$ As $n \to \infty$, because $|a| < 1$, $a^{n+1} \to 0$. The step response converges asymptotically to steady-state value $y[\infty] = \frac{1}{1 - a}$.

✍️ Try It Out Yourself: Oppenheim Chapter 2, Problem 2.7 (System Properties)

Question: For the following discrete-time systems, determine whether the system is (a) Linear, (b) Time-Invariant, (c) Causal, and (d) BIBO Stable:

  1. $y[n] = x[n] + 2$
  2. $y[n] = x[2n]$
  3. $y[n] = \sum_{k=-\infty}^n x[k]$
Click to Reveal Step-by-Step Solution

1. $y[n] = x[n] + 2$:
- Linear? NO. If $x[n] = 0$, $y[n] = 2 \neq 0$. Fails scaling axiom.
- Time-Invariant? YES. Shifting input gives $x[n-n_0] + 2 = y[n-n_0]$.
- Causal? YES. Depends only on current sample $n$.
- Stable? YES. If $|x[n]| \le B_x$, $|y[n]| \le B_x + 2 < \infty$.

2. $y[n] = x[2n]$ (Downsampler / Compressor):
- Linear? YES. Scaling and addition commute.
- Time-Invariant? NO. Time-scaled coefficients make it time-variant.
- Causal? NO. For $n = 2$, $y[2] = x[4]$ requires future input sample $x[4]$.
- Stable? YES. Output magnitude cannot exceed $|x[n]| \le B_x$.

3. $y[n] = \sum_{k=-\infty}^n x[k]$ (Accumulator):
- Linear? YES.
- Time-Invariant? YES.
- Causal? YES. Depends only on past and present inputs ($k \le n$).
- Stable? NO (Unstable). For bounded input $x[n] = u[n]$ ($|x| \le 1$), $y[n] = (n+1)u[n] \to \infty$ as $n \to \infty$.

3.1 Eigenfunctions of LTI Systems

When an LTI system with impulse response $h[n]$ is excited by a complex exponential $x[n] = e^{j\omega n}$:

$$y[n] = \sum_{k=-\infty}^\infty h[k] e^{j\omega (n - k)} = \left( \sum_{k=-\infty}^\infty h[k] e^{-j\omega k} \right) e^{j\omega n} = H(e^{j\omega}) e^{j\omega n}$$

Hence, complex exponentials are eigenfunctions of LTI systems, and the eigenvalue $H(e^{j\omega})$ is the Frequency Response of the system.

📖 Oppenheim Worked Example 2.19: Frequency Response of the Moving-Average System

Problem Statement: Find the frequency response $H(e^{j\omega})$ of the causal $(M+1)$-point moving-average filter whose impulse response is given by: $$h[n] = \begin{cases} \frac{1}{M+1}, & 0 \le n \le M \\ 0, & \text{otherwise} \end{cases}$$

Derivation:
Apply the definition of the DTFT: $$H(e^{j\omega}) = \sum_{n=0}^M \frac{1}{M+1} e^{-j\omega n} = \frac{1}{M+1} \sum_{n=0}^M (e^{-j\omega})^n$$ Using finite geometric series sum formula $\sum_{n=0}^M r^n = \frac{1 - r^{M+1}}{1 - r}$: $$H(e^{j\omega}) = \frac{1}{M+1} \frac{1 - e^{-j\omega (M+1)}}{1 - e^{-j\omega}} = \frac{1}{M+1} \frac{e^{-j\omega (M+1)/2} \left( e^{j\omega (M+1)/2} - e^{-j\omega (M+1)/2} \right)}{e^{-j\omega/2} \left( e^{j\omega/2} - e^{-j\omega/2} \right)}$$ Using Euler's identity $e^{j\theta} - e^{-j\theta} = 2j \sin\theta$: $$H(e^{j\omega}) = \frac{1}{M+1} \frac{\sin\left(\frac{\omega(M+1)}{2}\right)}{\sin\left(\frac{\omega}{2}\right)} e^{-j\omega M / 2}$$ Key Conclusions:
1. Magnitude Response: Scaled Dirichlet kernel (discrete sinc function) $|H(e^{j\omega})| = \frac{1}{M+1} \left| \frac{\sin(\omega(M+1)/2)}{\sin(\omega/2)} \right|$. Nulls occur at $\omega = \frac{2\pi k}{M+1}$ for $k = 1, 2, \dots, M$.
2. Phase Response: Exact linear phase with group delay $\tau_g = \frac{M}{2}$ samples for all $\omega$.

Question: Use Parseval’s Theorem to evaluate the total energy $E = \sum_{n=-\infty}^\infty |x[n]|^2$ of the sinc sequence: $$x[n] = \frac{\sin(\omega_c n)}{\pi n}$$

Click to Reveal Step-by-Step Solution

Solution:
Recall that $x[n] = \frac{\sin(\omega_c n)}{\pi n}$ is the inverse DTFT of an ideal brickwall lowpass filter: $$X(e^{j\omega}) = \begin{cases} 1, & |\omega| < \omega_c \\ 0, & \omega_c < |\omega| \le \pi \end{cases}$$ By Parseval’s theorem: $$E = \sum_{n=-\infty}^\infty |x[n]|^2 = \frac{1}{2\pi} \int_{-\pi}^\pi |X(e^{j\omega})|^2 d\omega = \frac{1}{2\pi} \int_{-\omega_c}^{\omega_c} (1)^2 d\omega = \frac{1}{2\pi} (2\omega_c) = \mathbf{\frac{\omega_c}{\pi}}$$

4.1 Definition & Relation to DTFT

The bilateral $z$-transform generalizes the Fourier transform to complex frequencies $z = r e^{j\omega}$:

$$X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n}$$

When evaluated on the unit circle ($|z| = r = 1$), the $z$-transform reduces identically to the DTFT: $X(e^{j\omega}) = X(z)\big|_{z = e^{j\omega}}$. For the DTFT to exist, the unit circle must lie within the Region of Convergence (ROC).

⭕ The Complex z-Plane: Unit Circle & ROC Boundaries (Figure 3.3)
Figure 4.1: The z-plane geometry (Oppenheim Fig 3.3). For causal systems, ROC is exterior to outermost pole. Stability requires the unit circle |z|=1 to lie inside the ROC.
📖 Oppenheim Worked Examples 3.1 & 3.2: Why Algebraic Expression Alone is Ambiguous without ROC

Example 3.1 (Right-Sided): Compute the $z$-transform of $x_1[n] = a^n u[n]$.
$$X_1(z) = \sum_{n=0}^\infty a^n z^{-n} = \sum_{n=0}^\infty (a z^{-1})^n = \frac{1}{1 - a z^{-1}}, \quad \text{converges for } |a z^{-1}| < 1 \iff \mathbf{|z| > |a|}$$

Example 3.2 (Left-Sided): Compute the $z$-transform of $x_2[n] = -a^n u[-n-1]$.
$$X_2(z) = -\sum_{n=-\infty}^{-1} a^n z^{-n} = -\sum_{m=1}^\infty a^{-m} z^m = -\sum_{m=1}^\infty (a^{-1} z)^m = 1 - \frac{1}{1 - a^{-1} z} = \frac{1}{1 - a z^{-1}}$$ Converges for $|a^{-1} z| < 1 \iff \mathbf{|z| < |a|}$.

Crucial MathWorks Screening Insight: Both sequences have the exact same algebraic rational expression $\frac{1}{1 - a z^{-1}}$. Without specifying the ROC, the inverse z-transform is completely ambiguous! If $|z| > |a|$, the sequence is causal; if $|z| < |a|$, it is anti-causal.

✍️ Try It Out Yourself: Oppenheim Chapter 3, Problem 3.4

Question: Given $X(z) = \frac{1 - \frac{1}{2} z^{-1}}{(1 - \frac{1}{4} z^{-1})(1 - 2 z^{-1})}$, find the sequence $x[n]$ for each of the following possible ROCs:

  1. $|z| > 2$
  2. $\frac{1}{4} < |z| < 2$
  3. $|z| < \frac{1}{4}$
Click to Reveal Step-by-Step Solution

Partial Fraction Expansion:
$$X(z) = \frac{A}{1 - \frac{1}{4} z^{-1}} + \frac{B}{1 - 2 z^{-1}}$$ Solving residues: $A = \frac{1 - 1/8}{1 - 8} = \frac{7/8}{-7} = -\frac{1}{8} \cdot \frac{8}{7}$ ... $A = \frac{1}{7}$, $B = \frac{6}{7}$.

1. ROC $|z| > 2$ (Outermost circle → Causal):
Both poles generate right-sided sequences:
$x[n] = \frac{1}{7}\left(\frac{1}{4}\right)^n u[n] + \frac{6}{7}(2)^n u[n]$ (Unstable, Causal).

2. ROC $\frac{1}{4} < |z| < 2$ (Annular ring including unit circle $|z|=1$):
Pole at $1/4$ is right-sided; pole at $2$ is left-sided:
$x[n] = \frac{1}{7}\left(\frac{1}{4}\right)^n u[n] - \frac{6}{7}(2)^n u[-n-1]$ (Stable, Non-causal / Two-sided).

3. ROC $|z| < \frac{1}{4}$ (Innermost circle → Anti-causal):
Both poles generate left-sided sequences:
$x[n] = -\frac{1}{7}\left(\frac{1}{4}\right)^n u[-n-1] - \frac{6}{7}(2)^n u[-n-1]$ (Anti-causal, Unstable).

5.1 The System Function (Transfer Function)

Applying the convolution property $\mathcal{Z}\{x[n] * h[n]\} = X(z) H(z)$, the system transfer function is:

$$H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{m=0}^M b_m z^{-m}}{1 + \sum_{k=1}^N a_k z^{-k}} = b_0 \frac{\prod_{m=1}^M (1 - c_m z^{-1})}{\prod_{k=1}^N (1 - d_k z^{-1})}$$

where $c_m$ are system zeros, and $d_k$ are system poles.

⚖️ Decision Flow: Causality and BIBO Stability Verification
Step 1
Compute Poles of System Function H(z)
Solve denominator polynomial roots: $1 + \sum_{k=1}^N a_k z^{-k} = 0 \implies d_1, d_2, \dots, d_N$.
Step 2
Check Pole Magnitudes for Causal System
For causality, ROC is $|z| > \max_k |d_k|$. For BIBO stability, unit circle $|z|=1$ must lie inside ROC.
Result
Stability Condition
A causal LTI system is BIBO stable if and only if all poles satisfy $|d_k| < 1$ (strictly inside the unit circle).

6.1 Periodic Sampling & Spectral Replication

Sampling a continuous signal $x_a(t)$ with interval $T$ creates discrete sequence $x[n] = x_a(n T)$. In the frequency domain, the spectrum of the sampled sequence $X(e^{j\omega})$ is an infinite periodic sum of shifted replicas of $X_a(j\Omega)$:

$$X(e^{j\omega}) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X_a\left( j\left(\frac{\omega - 2\pi k}{T}\right) \right)$$

where continuous frequency $\Omega$ and discrete frequency $\omega$ are linked by: $\omega = \Omega T$.

📖 Oppenheim Worked Example 4.1: Sampling and Reconstruction of a Continuous Sinusoid

Problem Statement: A continuous-time signal $x_a(t) = \cos(4000\pi t)$ is sampled with sampling period $T_s$. Determine the discrete sequence $x[n]$ and the reconstructed signal $x_r(t)$ when sampled with an ideal D/C reconstruction filter for:
(a) $T_s = 1/6000\text{ s}$ ($f_s = 6000\text{ Hz}$)
(b) $T_s = 1/3000\text{ s}$ ($f_s = 3000\text{ Hz}$)

Solution:
The frequency of $x_a(t)$ is $f_0 = \frac{4000\pi}{2\pi} = 2000\text{ Hz}$. Nyquist rate is $2 f_0 = 4000\text{ Hz}$.
Case (a): $f_s = 6000\text{ Hz} > 4000\text{ Hz}$ (No Aliasing):
$$x[n] = x_a(n T_s) = \cos\left(4000\pi \frac{n}{6000}\right) = \cos\left(\frac{2\pi}{3} n\right)$$ Since $f_s > 2 f_0$, the ideal reconstruction filter passes $2000\text{ Hz}$ unattenuated and suppresses all replicas. The reconstructed signal is identically: $$x_r(t) = \cos(4000\pi t) = x_a(t)$$ Case (b): $f_s = 3000\text{ Hz} < 4000\text{ Hz}$ (Under-sampled / Aliasing!):
$$x[n] = \cos\left(4000\pi \frac{n}{3000}\right) = \cos\left(\frac{4\pi}{3} n\right) = \cos\left(2\pi n - \frac{2\pi}{3} n\right) = \cos\left(\frac{2\pi}{3} n\right)$$ Notice that $x[n]$ in Case (b) is identical to Case (a)!
However, the D/C reconstruction filter for $f_s = 3000\text{ Hz}$ has bandwidth $[-1500, 1500]\text{ Hz}$. The apparent reconstructed frequency is: $$f_{\text{alias}} = |f_0 - f_s| = |2000 - 3000| = 1000\text{ Hz}$$ Therefore: $$x_r(t) = \cos(2\pi \cdot 1000 t) = \cos(2000\pi t) \neq x_a(t)$$ The original $2000\text{ Hz}$ tone has irreversibly morphed into an aliased $1000\text{ Hz}$ tone!

7.1 Decimation by Integer Factor $M$ (Downsampling)

Decimation reduces the sampling rate by factor $M$. To prevent aliasing at the lower rate, the signal must first pass through a digital anti-aliasing lowpass filter with cutoff $\omega_c = \pi / M$, followed by a compressor that retains every $M^{\text{th}}$ sample:

$$y[m] = x[m M], \quad Y(e^{j\omega}) = \frac{1}{M} \sum_{k=0}^{M-1} X\left(e^{j\frac{\omega - 2\pi k}{M}}\right)$$

Figure 7.1: Fundamental multirate operations (Oppenheim Fig 4.20 & 4.25). Downsampling requires an anti-aliasing filter before compression; upsampling requires an anti-imaging filter after expansion.
📖 Oppenheim Worked Example 4.5: Rational Sampling Rate Conversion by L/M

Problem Statement: Explain why an upsampler $(\uparrow L)$ must ALWAYS precede the downsampler $(\downarrow M)$ when performing rate conversion by a rational fraction $L/M$.

Solution:
1. If we downsample by $M$ first, we must lowpass filter to cutoff $\pi/M$, potentially discarding frequency components of the signal in the band $[\pi/M, \pi/L]$ if $L > M$.
2. If we upsample by $L$ first, the signal spectrum is expanded into $L$ replicas, but no information is discarded. We then follow with a single lowpass filter with cutoff $\omega_c = \min(\pi/L, \pi/M)$ and gain $L$. This single filter serves simultaneously as the anti-imaging filter for interpolation AND the anti-aliasing filter for decimation!
3. This cascade preserves maximum signal bandwidth and avoids redundant filtering stages.

✍️ Try It Out Yourself: Oppenheim Chapter 4, Problem 4.25 (Polyphase Noble Identities)

Question: State the first Noble Identity for decimation and explain why polyphase filtering achieves an $M$-fold computational speedup.

Click to Reveal Step-by-Step Solution

First Noble Identity: A digital filter $H(z^M)$ followed by a downsampler $\downarrow M$ is equivalent to a downsampler $\downarrow M$ followed by $H(z)$.
Polyphase Speedup: In direct decimation, we compute $N$ filter multiplications at sample rate $f_s$ and then throw away $M-1$ out of every $M$ outputs! In the polyphase structure, $H(z) = \sum_{k=0}^{M-1} z^{-k} E_k(z^M)$, using the noble identity we move the downsampler before the sub-filters $E_k(z)$. Thus, all multiplications occur at the decimated rate $f_s/M$, saving $M \times$ computational workload!

8.1 Statistical Model of Quantization Errors

When an analog voltage is quantized by a $(B+1)$-bit uniform analog-to-digital converter with full-scale range $[-X_m, X_m]$, the quantization step size is:

$$\Delta = \frac{2 X_m}{2^{B+1}} = \frac{X_m}{2^B}$$

Assuming the quantization error $e[n]$ is uniformly distributed between $[-\Delta/2, \Delta/2]$ and uncorrelated with the input signal, the quantization noise variance is:

$$\sigma_e^2 = \frac{\Delta^2}{12} = \frac{X_m^2 2^{-2B}}{12}$$

Problem Statement: An analog audio signal with dynamic range $[-5\text{ V}, 5\text{ V}]$ requires a Signal-to-Quantization-Noise Ratio of at least $90\text{ dB}$. How many ADC bits $B$ are required?

9.1 Phase and Group Delay

The frequency response of an LTI system is a complex function of frequency: $H(e^{j\omega}) = |H(e^{j\omega})| e^{j\theta(\omega)}$.

  • Phase Response: $\theta(\omega) = \arg H(e^{j\omega})$
  • Phase Delay: $\tau_p(\omega) = -\frac{\theta(\omega)}{\omega}$
  • Group Delay: $\tau_g(\omega) = -\frac{d}{d\omega} \left[ \theta(\omega) \right]$

📖 Oppenheim Worked Example 5.1: Group Delay of a First-Order System

Problem Statement: Compute the group delay $\tau_g(\omega)$ of the causal first-order system $H(z) = \frac{1}{1 - a z^{-1}}$ with $|a| < 1$.

Solution:
Evaluating on the unit circle: $$H(e^{j\omega}) = \frac{1}{1 - a e^{-j\omega}} = \frac{1}{1 - a\cos\omega + j a\sin\omega}$$ The phase response is: $$\theta(\omega) = -\arctan\left( \frac{a\sin\omega}{1 - a\cos\omega} \right)$$ Differentiating with respect to $\omega$ using $\frac{d}{d\omega}[\arctan(u)] = \frac{u'}{1 + u^2}$: $$\tau_g(\omega) = -\frac{d\theta(\omega)}{d\omega} = \frac{a^2 - a\cos\omega}{1 - 2a\cos\omega + a^2}$$ Physical Insight: For $a > 0$, the group delay peaks at $\omega = 0$ ($\tau_g(0) = \frac{a}{1 - a}$) and decreases monotonically toward $\omega = \pi$. Signals with spectral components near DC experience significantly more delay than high-frequency components!

📖 Oppenheim Worked Example 5.11: Factoring Non-Minimum Phase System into H_min(z) and H_ap(z)

Problem Statement: Factor the non-minimum phase system $H(z) = \frac{1 + 3 z^{-1}}{1 - \frac{1}{2} z^{-1}}$ into its canonical minimum-phase and allpass components.

Solution:
The pole is at $z = 1/2$ (inside the unit circle $\implies$ stable). The zero is at $z = -3$ (outside the unit circle $\implies$ non-minimum phase).
1. To make it minimum phase, reflect the zero inside the unit circle: $c_1 = -3 \to 1/c_1^* = -1/3$.
2. The minimum phase component with identical magnitude is: $$H_{\min}(z) = 3 \frac{1 + \frac{1}{3} z^{-1}}{1 - \frac{1}{2} z^{-1}}$$ 3. The allpass factor must satisfy $H(z) = H_{\min}(z) H_{\text{ap}}(z)$: $$H_{\text{ap}}(z) = \frac{H(z)}{H_{\min}(z)} = \frac{1 + 3 z^{-1}}{3 (1 + \frac{1}{3} z^{-1})} = \frac{z^{-1} + \frac{1}{3}}{1 + \frac{1}{3} z^{-1}}$$ Notice $|H_{\text{ap}}(e^{j\omega})| = 1$ identically for all $\omega$! 📖 Oppenheim Worked Example 6.1: Direct Form I vs. Direct Form II Realizations

Problem Statement: A second-order digital filter is described by: $$y[n] - 0.75 y[n-1] + 0.125 y[n-2] = x[n] + 0.5 x[n-1]$$ Compare the memory requirements (delay elements) of Direct Form I and Direct Form II.

- Saving 1 delay register reduces memory by 33%.

12.1 Sources of Finite-Wordlength Errors

E1
A/D Input Quantization
Quantizing continuous sensor samples to $B+1$ bits introduces white additive noise of variance $\sigma_e^2 = \Delta^2 / 12$.
E2
Coefficient Quantization
Truncating filter coefficients $b_k, a_k$ shifts pole and zero locations in the $z$-plane, distorting cutoff frequency and risking instability.
E3
Arithmetic Round-Off & Accumulation Noise
Multiplying two $(B+1)$-bit numbers yields a $2B$-bit product. Quantizing back to $(B+1)$ bits injects round-off noise into the feedback loop.
E4
Dynamic Range Overflow & Limit Cycles
In Two's complement arithmetic, positive overflow wraps around to large negative numbers, exciting sustained non-linear periodic oscillations (limit cycles).

📖 Oppenheim Worked Example 6.13: Zero-Input Limit Cycles in a First-Order System

Problem Statement: Consider a first-order recursive filter $y[n] = a y[n-1] + x[n]$ with $a = 0.9$. Assume fixed-point arithmetic with rounding to the nearest integer. If initial state is $y[-1] = 8$ and input is zero ($x[n] = 0$ for $n \ge 0$), compute the trajectory of $y[n]$.

$y[0] = \operatorname{round}(0.9 \times 8) = \operatorname{round}(7.2) = 7$
$y[1] = \operatorname{round}(0.9 \times 7) = \operatorname{round}(6.3) = 6$

13.1 Filter Design Specifications

Filter requirements are defined in four parameters:

  • Passband cutoff: $\omega_p$, Passband ripple: $\delta_1$ (or $R_p = -20\log_{10}(1 - \delta_1)\text{ dB}$)
  • Stopband cutoff: $\omega_s$, Stopband attenuation: $\delta_2$ (or $A_s = -20\log_{10}(\delta_2)\text{ dB}$)
  • Transition band: $\Delta\omega = \omega_s - \omega_p$
🔄 The 4-Step Bilinear Transformation Design Pipeline (Figure 7.5)
Step 1
Specify Digital Filter Cutoffs
Target discrete frequencies $\omega_p, \omega_s$ and ripple bounds $R_p, A_s$.
Step 2
Pre-Warp Analog Prototype Frequencies
$$\Omega_p = \frac{2}{T_s} \tan\left(\frac{\omega_p}{2}\right), \quad \Omega_s = \frac{2}{T_s} \tan\left(\frac{\omega_s}{2}\right)$$
Step 3
Synthesize Analog Prototype Transfer Function Ha(s)
Compute poles and zeros for analog Butterworth, Chebyshev, or Elliptic filter.
Step 4
Apply Bilinear Transformation (BLT)
Substitute $s = \frac{2}{T_s} \frac{1 - z^{-1}}{1 + z^{-1}}$ into $H_a(s)$ to obtain final discrete filter $H(z)$.
📖 Oppenheim Worked Example 7.3: Bilinear Transformation Design of a Butterworth Lowpass Filter

Problem Statement: Design a discrete-time lowpass filter meeting the specifications:
- Passband edge: $\omega_p = 0.2\pi$, Passband ripple $\le 1\text{ dB}$ ($\delta_1 = 0.89125$)
- Stopband edge: $\omega_s = 0.3\pi$, Stopband attenuation $\ge 15\text{ dB}$ ($\delta_2 = 0.17783$)
Use Bilinear Transformation with $T_s = 1$.

Solution:
1. Pre-warp frequencies (Oppenheim Eq 7.21): $$\Omega_p = \frac{2}{1} \tan\left(\frac{0.2\pi}{2}\right) = 2 \tan(0.1\pi) = 0.6498\text{ rad/s}$$ $$\Omega_s = \frac{2}{1} \tan\left(\frac{0.3\pi}{2}\right) = 2 \tan(0.15\pi) = 1.0191\text{ rad/s}$$ 2. Determine Butterworth Filter Order $N$: $$N \ge \frac{\log_{10}\left( \frac{10^{A_s/10} - 1}{10^{R_p/10} - 1} \right)}{2 \log_{10}(\Omega_s / \Omega_p)} = \frac{\log_{10}\left( \frac{10^{1.5} - 1}{10^{0.1} - 1} \right)}{2 \log_{10}(1.0191 / 0.6498)} = \frac{\log_{10}(30.62 / 0.2589)}{2 \log_{10}(1.568)} = \frac{2.073}{0.3908} = 5.30 \implies \mathbf{N = 6}$$ 3. Compute 6 analog Butterworth poles in left-half $s$-plane distributed symmetrically on circle of radius $\Omega_c$.
4. Map each pole via $s_k \to z_k = \frac{1 + s_k/2}{1 - s_k/2}$. Group complex conjugate pairs into 3 second-order cascade sections.

16.1 O(1) Circular Buffer for Streaming DSP in C

#include <stdlib.h>
#include <stdbool.h>

typedef struct {
    float *buffer;
    size_t capacity;
    size_t head;
    size_t count;
    double running_sum;
} RingBufferFilter;

RingBufferFilter* ring_init(size_t window_size) {
    RingBufferFilter *f = (RingBufferFilter *)malloc(sizeof(RingBufferFilter));
    if (!f) return NULL;
    f->buffer = (float *)calloc(window_size, sizeof(float));
    if (!f->buffer) { free(f); return NULL; }
    f->capacity = window_size;
    f->head = 0;
    f->count = 0;
    f->running_sum = 0.0;
    return f;
}

float ring_process(RingBufferFilter *f, float sample) {
    f->running_sum -= f->buffer[f->head];      // Subtract oldest sample
    f->buffer[f->head] = sample;               // Insert new sample
    f->running_sum += sample;
    
    // Power of 2 bitwise modulo optimization:
    f->head = (f->head + 1) % f->capacity;
    if (f->count < f->capacity) f->count++;
    return (float)(f->running_sum / f->count);
}
